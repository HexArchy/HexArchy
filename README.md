I build **internal developer platforms** — the layer that lets product teams ship without each of them reinventing networking, databases and tooling. Most of it is Go, and most of it sits one level below what users see.

### What I work on

- **Service mesh and traffic control** — one platform offering instead of several separate meshes. A service onboards in a single action; rate limits, timeouts and circuit breakers change at runtime, without a redeploy.
- **DBaaS** — cluster provisioning with full lifecycle management and an SDK that ships metrics out of the box. Provisioning takes minutes instead of days.
- **Agent infrastructure** — an MCP gateway in front of per-domain MCP servers: stateless, with tool search and scope-based authorization, so AI coding agents can reach internal infrastructure safely.
- **Developer tooling** — the small, sharp tools that hold the rest together.
