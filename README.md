# Nikita Belyakov

**Go platform engineer.** I build internal developer platforms — the layer that
lets product teams ship without each of them reinventing networking, databases
and tooling.

Currently on the IDP platform team at VK, working on service mesh consolidation

puts internal infrastructure behind AI coding agents.

---

### What I work on

**Service mesh & traffic control** — consolidating separate mesh solutions into
one platform offering, so a service onboards through a single action. Rate
limiting, timeouts and circuit breakers reconfigurable at runtime, without a
redeploy.

**DBaaS** — a platform for provisioning database clusters with lifecycle
management and an SDK that ships metrics out of the box. 100+ clusters for
product teams; provisioning went from days to minutes.

**AI / agent infrastructure** — an MCP Gateway aggregating per-domain MCP
servers: stateless with Redis-backed sessions, BM25 multilingual tool search,
OAuth scope-based authorization, and clients for Claude Code, Codex and OpenCode.

**High-load product backends** — before the platform work, a 2M+ MAU service in
the VK Health ecosystem on a DDD architecture, with ClickHouse analytics
pipelines behind it.
